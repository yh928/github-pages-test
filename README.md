# NEBULA STRIKE 🚀

우주 슈팅 게임 — 단일 HTML 파일, 의존성 0.

## 실행
브라우저에서 `index.html`를 열면 바로 실행됩니다.

## 조작
| 키 | 동작 |
| --- | --- |
| `← →` / `A D` | 좌우 이동 |
| `↑ ↓` / `W S` | 상하 이동 |
| `Space` | 발사 |
| `P` | 일시정지 |
| `Enter` | 시작 / 리타이 |

## 게임 규칙
- 웨이브마다 적 격파 수만큼 **웨이브 차지** 게이지가 차면 다음 웨이브로 진행
- 적 4종: 드론 / 지그재그 / 건슈터 / 헤비(고 HP)
- 웨이브 진행 시 적 HP·속도·탄속이 상승

## 파워업
- 💜 **3WAY** — 3방향 사격 (10초)
- 💛 **RAPID** — 발사 속도 2배 (8초)
- 💚 **SHIELD** — 보호막, 1회 피격 흡수 (6초)

최고 점수는 `localStorage`에 저장됩니다.
